# PhishShield 🛡

在主流搜索引擎的搜索结果中，自动**标记并隐藏**疑似钓鱼/欺诈网站。

支持引擎：**Bing / 百度 / 搜狗 / 360 搜索 / Google / DuckDuckGo**

## 为什么需要它

在搜索引擎搜「XX官网」「XX下载」时，前排结果常混入仿冒官网的钓鱼站点（诱导下载带木马的压缩包、骗取账号密码）。PhishShield 在你点开链接之前，先把这些结果标出来或直接隐藏。

## 检测机制

四层判定，全部本地执行，不上传任何搜索内容：

1. **内置黑名单** — 已确认的钓鱼域名（持续积累）
2. **启发式评分引擎** —
   - 品牌仿冒识别（编辑距离、连字符拼接、一字之差的变体拼写，覆盖 170+ 品牌与 67 款高频被仿冒软件）
   - 高危域名特征（IP 直连、危险 TLD、国内两段式后缀 + 仿冒信号组合）
   - 诱饵词识别（假「官网/下载/客服」文案、压缩包分发 .zip/.rar/.7z）
3. **订阅黑名单** — 每日自动拉取数十万条公开钓鱼域名列表（Phishing Army / malware-filter / Phishing.Database）
4. **可选增强** — Google Safe Browsing API

## 三种处置模式

| 模式 | 行为 |
|---|---|
| 仅标记 | 危险结果加醒目警告条，不隐藏 |
| 隐藏危险（默认） | 高危结果直接隐藏，中危标记 |
| 全部隐藏 | 隐藏所有非安全结果 |

## 安装

1. 下载并解压本仓库（或 Releases 中的 zip 包）
2. 打开 `chrome://extensions`，开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压后的目录
4. 到任意支持的搜索引擎搜索，即自动生效

> 首次启动后请稍等片刻，后台会自动下载订阅黑名单（约 10MB）。

## 目录结构

```
├── manifest.json        # MV3 清单
├── background.js        # Service Worker：订阅源拉取、黑名单查询、SB 增强
├── content.js           # 多引擎适配器 + 结果扫描/标记/隐藏
├── content.css          # 警告条样式
├── popup.html / popup.js    # 工具栏弹窗（统计与快捷开关）
├── options.html / options.js # 设置页（模式、灵敏度、自定义黑名单、订阅源）
└── common/
    ├── blacklist.js     # 内置钓鱼域名黑名单
    ├── brands.js        # 品牌库（170+）与软件清单（67 款）
    └── heuristics.js    # 启发式评分引擎
```

## 隐私

- 所有检测在本地完成，不收集、不上传搜索词与浏览记录
- 唯一网络请求：定时下载公开黑名单列表、（可选）向 Google Safe Browsing 提交可疑 URL 哈希
